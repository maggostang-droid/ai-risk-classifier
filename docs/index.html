Portfolio-Projekt · EU AI Act

Ist dein KI-System ein Hochrisiko-System? Und kannst du das beweisen?

Ein Tool, das einen KI-Use-Case deterministisch nach EU-AI-Act-Risikoklasse einordnet — und die Klassifizierung an einem echten, live ausgeführten metamorphen Test verifiziert, statt sie nur zu behaupten. Eine anwendbare Miniatur von Marco Stangs Promotionsthema zur Validierung von KI-Systemen.

GitHub-Repo ansehen Live-Demo (folgt in Kürze)

Was das Tool macht

Vier Schritte von der Use-Case-Beschreibung bis zum prüffähigen Nachweis.

1

Deterministisch klassifizieren

Ein editierbarer Fragebogen zu Annex-III-Kriterien läuft durch einen regelbasierten Entscheidungsbaum — keine Blackbox, jede Klasse ist nachvollziehbar begründet.

2

Begründung in Klartext

Ein LLM formuliert nur die Prosa-Begründung zur bereits feststehenden Klasse — es beeinflusst nie die Klassifizierung selbst.

3

Metamorph testen

Für den Automotive-Use-Case wird eine Monotonie-Relation gegen ein simuliertes Komfortsystem tatsächlich ausgeführt — mit echten Zahlen, nicht nur behauptet.

4

Governance-Artefakt

Für Hochrisiko-Fälle: Risk Assessment + Konformitätscheckliste (Art. 9–15) als Markdown, in-App lesbar und herunterladbar.

Warum das relevant ist

Das Thema ist keine Trend-Idee, sondern die direkte Anwendung von Marco Stangs Dr.-Ing.-Forschung (KIT/ITIV, 2019–2025) zur "Validierung von KI-Systemen durch Verknüpfung von Szenarien und metamorphes Testen" — erprobt in einer Industriekooperation mit Mercedes-Benz zu autonomen Fahrzeug-Komfortsystemen. Dieses Tool überträgt die Methodik in Miniaturform auf ein akut zeitrelevantes regulatorisches Thema.

Kein anderes Portfolio-Projekt kombiniert eine einschlägige Promotion mit einem Governance-/Compliance-Use-Case — das ist der Grund, warum dieses Projekt zuerst gebaut wurde.

Limitierungen

  • Keine rechtsverbindliche Compliance-Aussage, kein Ersatz für juristische Beratung oder ein echtes Konformitätsbewertungsverfahren.
  • Nur 3 fest hinterlegte Beispiel-Use-Cases, kein Freitext-Import.
  • Ein metamorpher Test (Monotonie-Relation), nicht die volle Szenario-Verknüpfungsmethodik der Promotion.
